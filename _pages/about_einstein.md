Numerous success stories have shown that a data-driven machine learning model will ultimately outperform approaches based on static rules set by human experts. Following this principle, my research interests lie in automated machine learning (AutoML) and dynamic efficient attention models. These include finding the optimal architectures for a given time-series forecasting task or adaptively sparsifying attention maps based on the input information. From a unified neural architecture search space for sequential structured data to dynamic sparse attention models that automatically allocate budgets to informative tokens,
I am working towards a machine learning system that adaptively fit to diverse context scenarios for better performance and efficiency.
